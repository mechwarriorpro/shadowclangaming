# Armour: three sets, three personalities

A remake of the old "armour with set bonuses" idea - three custom `ArmorMaterial`s, twelve pieces, our
own textures and our own mechanics.

---

## 1. The sets

| Set | Helmet | Chest | Legs | Boots | Toughness | Knockback res. | Enchantability |
|---|---|---|---|---|---|---|---|
| **Infamy** | 3 | 8 | 6 | 3 | 2.0 | 0.05 | 18 |
| **Sentinel** | 4 | 9 | 7 | 4 | 3.5 | 0.15 | 12 |
| **Raider** | 2 | 6 | 5 | 2 | 0.5 | 0.00 | 22 |

Durability is 28× the slot multiplier (the same scale vanilla uses), and each material's repair
ingredient matches its theme: netherite scrap + obsidian, iron, leather.

### Full-set bonuses (all four pieces)

| Set | Bonus | Price |
|---|---|---|
| **Infamy** | Resistance I, Strength I — and **Strength III below a third health** | Daylight burns you while the full set is worn |
| **Sentinel** | Regeneration I | You move slowly |
| **Raider** | Speed II, Jump Boost II, Night Vision | Thin armour, nothing else |

The Infamy penalty is deliberately shaped so it cannot kill you: it deals a *fraction of your maximum
health* per second (2 %), never a flat number, and it is skipped entirely if you are fire immune or
under a roof.

## 2. How set bonuses are applied

`armor/ArmorSets.java` runs once a second per player:

1. count how many pieces of each set are in the four armour slots
2. call `set.applyBonus(player, count)` — a no-op below four pieces
3. if the heaviest set is Infamy at full strength, apply the sunlight damage

Effects are refreshed with a **2 second duration every 1 second**, never stacked. Take one boot off and
the bonus is gone within two seconds, with no bookkeeping and nothing to desync.

## 3. How armour textures work on 1.21.1

This is the part that trips people up. On **1.21.1** an armour material points at texture *layers*:

```java
new ArmorMaterial(
    Map.of(ArmorItem.Type.HELMET, 3, ...),   // defence per slot
    18,                                      // enchantability
    SoundEvents.ARMOR_EQUIP_NETHERITE,       // equip sound
    () -> Ingredient.of(Items.OBSIDIAN),     // repair item
    List.of(new ArmorMaterial.Layer(ResourceLocation.fromNamespaceAndPath("shadowclangaming", "infamy"))),
    2.0F,                                    // toughness
    0.05F);                                  // knockback resistance
```

The layer's asset name resolves to:

```
assets/shadowclangaming/textures/models/armor/infamy_layer_1.png    (the body)
assets/shadowclangaming/textures/models/armor/infamy_layer_2.png    (the trim overlay)
```

Both are 64×32 and are generated by the build script in this repo. **1.21.2 moved this to a separate
equipment-asset JSON system** — if you later port this mod forward, that is the file to rewrite, and
nothing else in this document changes.

## 4. Files

| File | Role |
|---|---|
| `registry/SCGArmorMaterials.java` | The three materials, their defence, toughness, layers |
